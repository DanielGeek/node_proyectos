# Simple CRUD with Node/Express and MongoDB

# endpoints
- Get all products GET http://localhost:3000/api/products
- Insert a Product POST http://localhost:3000/api/products
- Get product by id GET http://localhost:3000/api/products/{productId}
- Update a producto PUT http://localhost:3000/api/products/{productId}
- Delete a product DELETE http://localhost:3000/api/products/{productId}

- Product body `{
    "name": "Pizza updated",
    "price": 6.99
    "quantity": 10
}`
